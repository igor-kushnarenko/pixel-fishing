# Pocket Fishing (pixel-fishing)
Уютная 2.5D-рыбалка в иллюстрированной бухте. Vite + Three.js.

Запуск: `npm install && npm run dev`, сборка: `npm run build` (папка `dist/`).

Управление: тап/клик по свободной воде справа от рыбака — закинуть;
при надписи «КЛЮЁТ!» и индикаторе над поплавком — тап/клик по игровому полю, чтобы подсечь.
Заброс на сушу, причал или корпус лодки не принимается.

Карта: перетаскивание — обзор, колесо мыши или щипок двумя пальцами — масштаб.
Кнопки `+` и `−` приближают/отдаляют, кнопка с процентом показывает всю карту.
На игровом поле Space/Enter — заброс/подсечка, стрелки — обзор, `+`/`−` — масштаб, `0` — вся карта.

Лодки покачиваются независимо от фона. По воде идут заметные прерывистые гребни волн,
двигаются блики и отражения; вдоль пляжа и волнореза проходит пенный прибой.
Рябь ограничена маской воды, чтобы не деформировать здания, причалы и скалы.
Дым поднимается из труб, фонари мягко мерцают, луч маяка вращается.
При `prefers-reduced-motion: reduce` декоративные анимации останавливаются.
При открытии коллекции или скрытии вкладки рыбалка не теряет время подсечки.
Карта рисуется в полном разрешении без старого пиксельного фильтра.

Графика хранится локально: `public/art/harbor.png` (фон) и
`public/art/harbor-sprites.png` (лодки, рыбак, дым). Описание подготовки и
точные промпты: [docs/harbor-assets.md](docs/harbor-assets.md).

Проверки: `npm test`, затем `npm run build`.

Деплой: в настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**.
Единственный workflow `.github/workflows/deploy.yml` запускается при push в `main`
или вручную, проверяет игру, собирает `dist/` и публикует на GitHub Pages.
Относительная база Vite `./` поддерживает адрес с префиксом `/pixel-fishing/`.

В игре пять видов рыб с разным окном подсечки (0,4–0,9 с). За каждую рыбу
начисляются очки. Весь цикл дня и ночи длится 3 минуты; ночью редкая рыба
встречается чаще. Звук синтезируется в браузере и выключается кнопкой в углу.
Клавиши Space/Enter на игровом поле работают как тап.

Очки, счётчики видов и лучший улов (самая дорогая пойманная рыба) сохраняются
в `localStorage` под ключом `pixel-fishing-v1`. Кнопка «Улов» открывает коллекцию
и ставит рыбалку на паузу. Если хранилище недоступно, играть всё равно можно.

Добавление на домашний экран: откройте опубликованную игру через HTTPS и
выберите в меню браузера «Установить приложение» или «На экран Домой»
(название зависит от браузера). Добавлены manifest, PNG-иконки 192/512 px
и иконка Apple 180 px. Офлайн-режим не реализован.
Пересоздать PNG-иконки из пиксельных примитивов: `node scripts/generate-icons.mjs`.

## Ходьба по карте (feature/walking)
- **Компьютер:** WASD или стрелки — ходить; клик по земле — идти туда (обход препятствий, A*).
- **Телефон:** касание по земле — идти; касание по воде вдали — дойти до берега и повернуться к воде.
- Забросить можно только стоя у края причала или берега лицом к воде — над рыбаком появляется «тап — забросить»; тогда касание по воде (или пробел/Enter) делает заброс.
- Камера плавно следует за рыбаком (кнопка ◎), позиция камеры привязана к пиксельной сетке экрана. Перетаскивание/щипок отключают следование.
- Зоны ходьбы и препятствия: `WALK_POLYGONS` и `OBSTACLES` в `src/harbor-map.js`; движение — `src/player.js`, поиск пути — `src/pathfinding.js`.
