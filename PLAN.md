# План развития для Codex (1 шаг = 1 коммит)

1. **Типы рыб.** «В src/main.js добавь массив FISH_TYPES (5 видов: name, color, size, rarity, points). При поимке выбирай вид по весам rarity, крась модель рыбы в его цвет и масштаб, показывай имя в HUD. Счётчик считай в очках. Коммит: "feat: fish types"».
2. **Мини-игра подсечки.** «Сделай окно поклёвки зависимым от вида рыбы (редкие — короче, 0.4–0.9 с). Добавь визуальный индикатор над поплавком (пиксельный «!»). Коммит: "feat: bite window per fish"».
3. **Звуки.** «Добавь src/audio.js на WebAudio без файлов: всплеск при забросе, «бульк» при поклёвке, джингл при поимке. Кнопка mute в углу, AudioContext стартует по первому тапу. Коммит: "feat: procedural sfx"».
4. **День/ночь.** «Добавь цикл суток 3 минуты: меняй цвет/интенсивность Hemisphere и Directional света, цвет воды; ночью другие веса редкости рыб. Коммит: "feat: day-night cycle"».
5. **Сохранение.** «Сохраняй в localStorage ключ pixel-fishing-v1: очки, число пойманных по видам, лучший улов. Загружай при старте. Коммит: "feat: save to localStorage"».
6. **Коллекция.** «Добавь кнопку «Улов» — HTML-оверлей со списком видов (пойманные/неизвестные «???») и счётчиками. Удобно на мобильном. Коммит: "feat: catch log"».
7. **Окружение.** «Добавь воксельные деревья/камыш на берегу и покачивание камыша по целым пикселям 8 fps; уважай prefers-reduced-motion. Коммит: "feat: scenery"».
8. **Деплой на GitHub Pages.** «Добавь .github/workflows/deploy.yml: на push в main — npm ci, npm run build, actions/upload-pages-artifact (dist) и actions/deploy-pages. vite base уже './'. Коммит: "ci: github pages deploy"».
9. **PWA (опционально).** «Добавь manifest.webmanifest и простую иконку, чтобы игру можно было добавить на домашний экран телефона. Коммит: "feat: pwa manifest"».
